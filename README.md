# IP 計算機（IPv4）

網址：https://rayminc.github.io/ip-calculator/

輸入 IP 和遮罩，馬上算出網段、廣播位址、可用範圍、主機數和萬用遮罩（wildcard）。版面參考 iPhone App「Subnet Calc」。

## 怎麼用
- 輸入框可以打 `192.168.1.25`、`192.168.1.25/24`、`192.168.1.25 255.255.255.0`，也可以貼萬用遮罩（`10.0.0.1 0.0.0.255` 會換算成 /24）。
- 遮罩位元數可以用滑桿、−／＋，或直接改 / 後面的數字。
- 點任何數值就能複製；下方按鈕可以一鍵複製 CIDR 或 ACL 寫法（`192.168.1.0 0.0.0.255`）。
- /31 照 RFC 3021 當點對點（兩個位址都能用），/32 是單一位址。

## 隱私
全部在瀏覽器裡計算，不會送出任何資料；只用瀏覽器的 localStorage 記住上次輸入和顯示設定。
也可以把 `index.html` 下載下來，離線點兩下打開。
